

# Declaring variables

Integers:

int x; # initializes a variable x, but does not assign it
int x = 567; # initializes a variable x and assigns it

x = 600; # updates x to 600

Doubles: # this is just a float

double price = 9.99;

Booleans:

boolean done = false;

Characters: 

char grade = 'A'; # must use single quotes for exactly one character.


Strings:

String name = "Nikolas"; # strings go in double quotes



Loops, Arrays, and Methods Translation Table:

while x < 10:		|  while (x < 10){}

len(name)		|  name.length() -- parenthesis on String
